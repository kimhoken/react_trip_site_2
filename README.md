# Trip Heaven ✈️

React 기반 국내·해외 여행 패키지 검색 및 예약 웹사이트입니다.

---

## 📌 프로젝트 소개

Trip Heaven은 사용자가 여행 상품을 조회하고  
예약 및 결제까지 진행할 수 있도록 구현한 여행사 웹 프로젝트입니다.

---

## 🛠 기술 스택

- React
- JavaScript
- React Router
- CSS
- LocalStorage

---

## ✨ 주요 기능

### 👤 회원 기능
- 로그인 / 회원가입
- 비밀번호 찾기 및 재설정
- 마이페이지

### 🔍 여행 상품 기능
- 국내 / 해외 여행 상품 조회
- 여행 상품 검색
- 평점 / 가격 / 리뷰 기준 정렬
- 인기 여행지 확인

### 🧳 예약 기능
- 여행 상품 예약
- 출발 날짜 선택
- 예약 내역 확인

### 💳 결제 기능
- 결제 모달 구현
- 결제 수단 선택
- 결제 정보 입력

### ⭐ 기타 기능
- 즐겨찾기
- 여행 팁 게시판
- 고객센터 페이지
